# User Stories

## Customer

### US-001 Enquire About Property

As a customer, I want to send a natural-language enquiry so I do not
need to fill a long form.

**Acceptance criteria** - Customer can submit a message. - Message is
stored. - Customer receives a response.

### US-002 Provide Requirements Gradually

As a customer, I want to provide budget, location, property type, and
timeline across multiple messages.

**Acceptance criteria** - Information from later messages updates the
lead. - Existing information is preserved. - Missing information can
trigger a clarification question.

### US-003 Request Human Assistance

As a customer, I want to speak with a sales representative.

**Acceptance criteria** - Human-agent intent is recognized. -
Appropriate handoff/notification process is triggered.

## Sales

### US-004 View Leads

As a sales user, I want to see incoming leads.

### US-005 Prioritize Leads

As a sales user, I want to see lead score and classification.

### US-006 View Conversation

As a sales user, I want to see the customer's conversation and extracted
requirements.

### US-007 Follow Up

As a sales user, I want to create and complete follow-up actions.

## Administrator

### US-008 Operate the System

As an administrator, I want to monitor system health, integrations, and
failures.
