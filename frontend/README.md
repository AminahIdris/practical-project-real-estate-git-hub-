# Frontend (React + Vite)

## Planned screens (TECHNICAL_SPEC)

- Customer enquiry / chat interface
- Sales login
- Lead list
- Lead detail
- Conversation view
- Qualification display
- Follow-up interface

## Local development

```bash
cd frontend
npm install
npm run dev
```

App runs at http://localhost:3000  
API calls are proxied to the backend (see vite.config.ts).
